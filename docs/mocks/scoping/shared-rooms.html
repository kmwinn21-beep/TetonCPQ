Rooms with more than one resident

Companion suites and semi-private rooms: two residents share one room. They need one Edge unit (it's per room) but a sensor and a pendant for each resident, and each resident is a billed bed. Today the system assumes one resident per room, so neither workaround is right.

Decisions

1. Monthly fee: per resident or per room?Software and support scale with residents, and it's how pricing reads today ("per bed").
Recommendation: per resident.
2. Installation (subscription): per Edge unit or per resident?The install work is per room; the 2nd resident's sensor is charged as an additional sensor.
Recommendation: per Edge unit + additional sensors.
3. Equipment purchase: what does the 2nd resident pay?The base package includes an Edge unit, so charging it twice over-prices the room.
Recommendation: one base package per room, the 2nd resident at the additional-sensor price.
4. Rooms that are only sometimes sharedA separate room type ("AL Companion") is simplest and matches how the floor plan is tagged.
Recommendation: room types now; add a per-badge "×2" override later only if reps ask for it.
5. OccupancyOccupancy already applies to billed beds, so a half-filled shared room is covered by the community's occupancy rate. No separate setting.
Recommendation: no change.
