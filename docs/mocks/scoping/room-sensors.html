More than one sensor in a room

A room with two residents (or a bedroom plus a living area) gets a sensor per bed, all on the room's one Edge unit. The system already counts this for room types. What's missing is setting it for one individual room, and seeing the sensor breakdown per room.

1 · How it's counted today

Every room has one Edge unit, and its first sensor comes with the Edge unit. Every sensor after that is an additional sensor on the same Edge unit (up to 3 per Edge unit).

4 · What needs to be done

  1. Per-room sensors and residents. Two more optional numbers on each tagged room (like the Edge units override), saved with the room types. Kept only when they differ from the room type.
  2. Popover. "This room only" shows Residents, Sensors and Edge units. Sensors follow residents until changed by hand; a breakdown line reads "1 Edge unit · 2 sensors (1 included, 1 additional)". The amber hint shows past 3 sensors per Edge unit.
  3. Math. Rooms tagged on the plan use their own numbers. Beds = Σ residents; additional sensors = Σ sensors − rooms (each room's first sensor is included), plus the contingency. Same rules as today, now per room. Price follows automatically: monthly fee per resident, one installation per room, additional sensors at the sensor price.
  4. Totals. The bottom bar shows the additional sensor count; the Summary table and scope PDF get Residents, Included and Additional columns and a footnote listing rooms set individually.
  5. Markers. A room set to 2 residents gets the ×2 marker on its badge.
  6. Tests. A single companion room inside a type of singles: beds +1, additional sensors +1, installation unchanged; overrides that match the type are dropped.

Decisions

1. Can one room change residents (billed beds), not just sensors?Residents change the monthly fee; sensors only change the one-time additional-sensor charge. A one-off companion room needs both.
Recommendation: yes, both, with sensors following residents.
2. Only rooms tagged on a floor plan?Overrides live on a tagged room. Room types typed in by hand (no plan) keep using their per-room numbers.
Recommendation: yes. For typed-in counts, a separate room type ("One Bedroom, shared") still works.
3. Show "included / additional" to the prospect?The proposal Scope page lists sensors in total today.
Recommendation: keep the proposal showing total sensors; show the included/additional split in Scope Mode and the scope PDF (internal).
