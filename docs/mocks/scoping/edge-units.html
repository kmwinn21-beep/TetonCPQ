Edge units in Scope Mode

Today Scope Mode counts rooms and sensors, and every room quietly gets one Edge unit. This adds an Edge units per room counter on each room type (default 1), shows the Edge units on each room's badge and popover, and puts the total next to rooms and sensors everywhere Scope Mode adds things up.

1 · The plan, with Edge units counted

The bottom bar gains an Edge units total. Badges only get a marker when a room's count isn't the usual 1, so a normal plan doesn't get busier. Example: the two-bedroom suites need 2 Edge units each.

5 · What needs to be done

  1. Total in Scope Mode (small, no pricing change). Add the Edge units count to the bottom bar, the Summary tab and the room popover, using today's rule (1 per room). This alone answers "how many Edge units is this plan?"
  2. Edge units per room on the room type. A new number on each room type (default 1, so nothing changes for existing deals), saved with the room types. Counter in the Scope Mode form and on the deal page room type card; sensors can't go below it.
  3. Math. Edge units = Σ rooms × Edge units per room. Additional sensors = sensors − Edge units (each Edge unit's first sensor is in its base price). This is the same "Edge units" figure shared rooms introduced, so installation, the equipment-purchase base package, hardware cost, the proposal Scope page and the live preview all follow it with no extra work.
  4. Badge marker. The purple Edge marker on badges and room type chips, only when the count isn't 1; also on the downloaded floor plan and scope PDF.
  5. (Optional) per-room override. A per-badge Edge count that differs from its type. Adds a field to each tagged room and an "override" note in Summary. Only if you want it (decision 1).
  6. Tests and checks. Pricing tests for a 2-Edge room on subscription and equipment purchase; desktop and phone checks of the form, popover and bar.

Decisions

1. Counter on the room type, or on each individual room too?Room types already carry sensors and pendants per room, and rooms of one type are almost always the same. A per-room override handles the odd one but adds a second place to look.
Recommendation: room type now (steps 1–4); add the per-room override only if reps hit odd rooms often.
2. Does a 2nd Edge unit in one room cost the customer more?Following the shared-rooms rule, installation and the equipment-purchase base package are per Edge unit, so a 2-Edge room pays 2 installations (or 2 base packages) and its first 2 sensors are included.
Recommendation: yes, per Edge unit, consistent with what you approved for shared rooms. The monthly fee stays per resident.
3. Can a room have 0 Edge units?e.g. a small bathroom-only room covered by the neighbor's Edge unit.
Recommendation: minimum 1 for now; it keeps "rooms" and "Edge units" from drifting in confusing ways.
