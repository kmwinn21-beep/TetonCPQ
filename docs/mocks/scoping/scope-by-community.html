How it works

Columns

  • [Care] Units: one column for each care setting in the deal (AL, MC, IL, SNF, or a custom setting's initials, using the same abbreviations as the short care names). Settings the deal doesn't have get no column.
  • Long headers wrap onto two lines (Total / Units) so all 8 columns fit on a letter-size page.
  • Total Units: rooms (the old "Apartments").
  • Beds: residents, with shared rooms counted twice.
  • Sensors: the total, with the math below it, e.g. 75 Incl. + 57 Addl. One sensor is included per bed, and the contingency is in the Addl. number.
  • Edge Units: one per room unless a room was set to more.
  • E-Call Pendants or E-Call Pull-Cords, depending on the system. Only shown when E-Call is in the deal.

Decisions for you

  1. Drop the "Extra sensors" column. The Addl. number under Sensors is the same figure, and dropping it frees room for the E-Call column. Recommended.
  2. Common area sensors: when a community has them, the subtext adds a third part (75 Incl. + 57 Addl. + 6 CA). The existing "Rooms only" switch leaves them out.
  3. E-Call subtext: show the math under the device count too (75 rooms + 4 allowance)? I left it plain to keep the row light.
  4. Hidden switch: "Care: Full | Short" is hidden in this view because the headers are always abbreviated.
